# BRS Availability Green Fees And GolfNow Case Evidence

Use this approved support evidence when a customer asks about members unable to book, visitor availability, 9-hole versus 18-hole setup, course restrictions, green fee rates, GolfNow display, Hot Deals, or external-channel availability.

## Member and visitor availability after a hole-count/course change

Do not answer a 9-hole/18-hole availability issue with competition purse, billing, or generic green-fee setup alone. Split the checks across the booking rule and inventory areas:

1. Confirm the affected course/date is set up as the correct hole product for the date being tested.
2. Open Tools -> Member Casual Booking Rules for member online booking access.
3. Check Course, Start Date, End Date, Start Time, End Time, Type (View or Book), Days Advance Booking, weekdays, player limits, guests allowed, and membership type applicability.
4. Open Tools -> Green Fee Rates for staff/manual rates and member/guest applicability.
5. Check Category, Sub Category, Holes, Start Date, End Date, Rates, Mem Types, Default, and Global.
6. Confirm there is a 9-hole row for the relevant member or visitor route when the course/date should be 9 holes.
7. Open Tools -> Course Restriction.
8. Check active and expired restrictions for date/time, player types, max group size, and message.
9. Check visitor online booking/public availability for the same date and tee time.
10. Check visitor/agent/GolfNow or Hot Deals inventory separately because the external channel can display differently from member booking rules.

Use one affected membership type, one visitor channel, one date, and one tee time as the test case before making wider changes. If BRS availability and rates look correct but GolfNow still shows the wrong hole count or no availability, escalate with screenshots of BRS visitor availability and the GolfNow display.
