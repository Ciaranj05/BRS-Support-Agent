# BRS Contacts And Reporting Case Evidence

Use this approved support evidence when a customer asks about missing contacts, tour operators, hotels, contact categories, contact exports, guest-count reports, or broad reporting help.

## Missing contact, tour operator, hotel, company, society, or visitor

Contacts stores non-member records. Do not route a missing tour operator, hotel, company, society, or visitor contact to Memberships unless the user says the person is a member.

Diagnostic checks:

1. Open Contacts.
2. Use View All or the full contacts list.
3. Clear category, site, status, or search filters that could hide the record.
4. Search by partial company/person name.
5. Filter by Contact Category such as Tour Operator, Hotel, Society, Company, Visitor, Other, or a club custom category.
6. Compare the expected and current count for the affected category/site if the club provides counts.

If the user asks how to re-add the missing contact:

1. Open Contacts.
2. Choose Add New.
3. In General Information, enter the Company / Group Name for an organisation or the person details for an individual.
4. Choose the Contact Category.
5. Add supplied email, telephone, mobile, address, town/city, county/state, country, and postcode/zip fields where relevant.
6. Set marketing preferences only according to the contact's permissions.
7. Save.
8. Return to View Contacts or View All.
9. Search/filter the same category/site and confirm the expected count.

If the old record later reappears, check booking or revenue history before deleting or replacing duplicates.

## Guest-count report for a member

If a user asks how many guests a member has booked over a specified period, there may not be one exact guest-count report. Give the closest reporting route:

1. Open Reports.
2. Use Booking Details or Full Booking Details.
3. Set Start Date, End Date, and Course where relevant.
4. Filter/search for the member where the report supports it.
5. Export or download CSV if available.
6. Count guest/player rows for that member in the exported report.

Use Booking / Payment Status when payment or completion status matters. Use user/member or playing-statistic reports only when the question is about member playing history rather than guests booked by that member.

## Broad reporting help

For "can you help me use reports better", start with Reports, Type of Report, Start Date, End Date, Course, Submit, Print, and export/download where available. Then ask what outcome they want: bookings, payments, memberships, contacts, revenue, utilisation, users, or playing statistics.
