# BRS Memberships Billing And Flex Case Evidence

Use this approved support evidence when a customer asks about member billing, prorated bills, one-member bills, subscriptions, payment schemes, flexible memberships, linked users, or member wallets.

## Single-member prorated membership bill

When the question is about one new or existing member, prefer the individual member route over the batch bill wizard:

1. Open Memberships.
2. Open Members.
3. Create or find the member profile.
4. Set or confirm the Membership Type and membership dates.
5. Open that member's billing/bills area.
6. Create or add the bill or charge for that member.
7. Use a clear Billing Reference or description.
8. Set the Due Date.
9. Set the bill period/start/end dates to the prorated period, not the full annual cycle, when the bill is not for the full cycle.
10. Add the relevant subscription if it exists, or use ADD ITEM for a one-off prorated membership charge.
11. Use quantity 1 and the calculated prorated amount.
12. Leave Payment Schemes blank unless the club wants instalments or scheduled payments.
13. Preview before confirming or publishing.
14. Check member, reference/description, due date, period dates, line item, amount, payment scheme, publish status, and total.

For batch billing, use Memberships -> Billing/Payments -> CREATE BILLS. The bill wizard uses Billing Reference, Due Date, Set Bill Filters, cycle/period information, Who To Bill, subscriptions/custom bill items, Payment Schemes, Preview, Review/Confirm, and Publish Bill.

## Flexible member not appearing

If a person appears in Users or BRS users but not Memberships, Flex Members, or Flexible Memberships, do not assume the Memberships profile is visible. Users and Memberships records are linked, but a visible user account does not prove that the Memberships profile/filter is present.

Check:

- The Users record and whether it is linked to a Memberships member profile.
- The linked member profile, if it exists.
- The Membership Type on the member profile.
- The Flex flag on the Membership Type.
- Memberships dashboard FLEX MEMBERS or Members/Flex view.
- Club Systems mapping, member category mapping, import, preview, or sync evidence before creating a duplicate profile.

Use Memberships -> Membership Types to create or edit a flexible membership type. Use Members for one member. Use Accounts for wallet/account setup. Use the member profile or flexible dashboard for one member's balance, top-up, or clawback.
