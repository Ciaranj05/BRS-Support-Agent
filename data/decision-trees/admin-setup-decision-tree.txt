## 1. IDENTIFY SETUP AREA

IF user asks generally about setup/configuration:

Ask:
“What are you trying to configure — green fee rates, booking rules, buggy booking, email templates, users, tee sheet settings, or membership/billing settings?”

IF area is clear:
→ Go directly to that section.

---

## 2. GREEN FEE RATES

IF user asks about green fee rates:

→ Use direct answer route green-fee-rates.

Escalate if:
- Rate does not apply
- Live price differs from setup
- Multiple clubs/rates are affected

---

## 3. BOOKING RULES

IF user asks about booking rules/restrictions:

→ Use direct answer route booking-rules.

Escalate if rule saves but does not apply.

---

## 4. BUGGY BOOKING / BUGGY AVAILABILITY

IF user asks about buggy booking, buggy availability, buggy count, number of buggies, visitor buggy booking, enabling buggies online, changing buggy settings, or any other buggy-related question:

→ Use direct answer route buggy-booking-availability.

If the user's buggy question is not covered by the approved answer, be transparent that the current approved buggy guidance only covers buggy booking setup and availability.

Do not ask a follow-up question if the user is asking about buggies.

Escalate if:
- Buggy settings do not save after clicking Update
- Buggy counts do not appear on the timesheet after setup
- Online buggy availability does not match the configured number of buggies
- Visitors cannot book buggies even though the setting is enabled

---

## 5. EMAIL TEMPLATES

IF user asks about emails/templates:

→ Use direct answer route email-templates.

Escalate if:
- Template does not save
- Emails are not sending
- Merge fields display incorrectly

---

## 6. TEE SHEET SETUP

IF user asks about tee sheet setup, timesheet setup, opening/closing times, tee intervals, blocked times, booking slots, member/visitor availability, or configuring the tee sheet:

→ Use direct answer route tee-sheet-setup.

Escalate if live tee sheet does not match setup.

---

## 7. USER / PERMISSION SETUP

IF setup request involves users, admins, staff, login or permissions:

→ Use user-management decision tree.

---

## 8. MEMBERSHIP / BILLING SETUP

IF setup request involves members, bills, subscriptions or payment schemes:

→ Use memberships decision tree.

---

## 9. ESCALATION TRIGGERS

Escalate if:

- Setting does not save
- Live system result does not match setup
- Multiple clubs/users affected
- User is unsure which configuration controls behaviour
- Configuration may affect payments, billing or customer access

---

## KEY BEHAVIOUR

Always:
- Confirm the setup area only when it is unclear
- If the setup area is clear and a direct route exists, return the approved answer without asking a follow-up question
- Give exact checks
- Confirm before changing live customer/member-facing settings

Never:
- Guess which setting controls behaviour
- Recommend changing live setup without confirmation
- Invent navigation paths that are not present in the approved knowledge
