Support style:
- Tools is the setup/configuration area. Use it for settings rather than day-to-day operational records.
- Give exact navigation only when confirmed.
- Warn users that Tools access is permission-controlled.
- Do not hard-code club-specific values such as rates, intervals, course names, custom terms, or enabled feature states.

Priority answer cues:
- For a member/visitor availability problem after a course changes between 18 holes and 9 holes, split the checks across course/hole setup, Tools > Member Casual Booking Rules, Tools > Green Fee Rates, Tools > Course Restriction, and visitor/agent/GolfNow inventory. Do not answer with competition purse or billing workflows.
- Member Casual Booking Rules controls when members can view/book online. Check Course, Start Date, End Date, Start Time, End Time, Type (View or Book), Days Advance Booking, weekdays, player limits, guests allowed, and whether the rule applies to all membership types, selected types only, or all except selected.
- Green Fee Rates controls category/sub-category/hole/date/rate/member-type applicability. Check that the relevant member or visitor route has a 9-hole row for the affected date range, not only an 18-hole row.
- Course Restriction can hide/block availability by date/time, player type, max group size, and message. Check active and expired restrictions before changing rates.
- For GolfNow or Hot Deals showing the wrong hole count or no availability, first confirm BRS visitor availability and visitor/agent rate/inventory setup for the same date/time; escalate if BRS is correct but the external channel still displays incorrectly.

## System Configuration

System Configuration controls broad club/system settings and feature switches.

Known use cases:

- Club address and email style parameters.
- Enabling/disabling features.
- Display Configuration.
- Enable Daily Dashboard.
- Calendar End Year.
- Search options.
- Nightly backup email.
- Marketing consent display.
- Playing time.
- Course names for multi-course/36-hole setups.
- Buggy booking settings.
- Single booking report settings.
- Revenue report settings.
- Club website settings.
- Members Booking module registration/login, casual golf, competition golf, general settings, and Club House PC/swipe-card settings.
- Visitor Booking module display, general, and credit-card settings.
- Online merchant/BRS Payments settings.
- Competition purse, waiting list, tour operator, and green fee printer settings.

Use System Configuration when the user asks about changing global behaviour, enabling dashboard display, setting up future years, or broad system parameters.

Important confirmed paths:

- Disable/enable Daily Dashboard: Tools > System Configuration > Display Configuration > Enable Daily Dashboard.
- Prepare future timesheet year: Tools > System Configuration > Calendar End Year.

Only admin users with Tools access should change System Configuration.

The System Configuration page includes question-mark help icons beside many settings. The help text is setting-specific and should be treated as the safest source when explaining a particular parameter. Verified help examples include:

- Club contact fields control details that appear on pages, reports, letters, and confirmation emails.
- Latitude and longitude are used to calculate sunrise and sunset times.
- Calendar start/end years control the years selectable across the system and affect many pages.
- Display Green Fee Rates on Timesheet adds green-fee dropdowns to the booking form on the Timesheet page.
- Display Handicap, Club and CDH fields affects Booking Detail and Visitor Booking Personal Details; CDH is only shown for online open competition bookings.
- Display Arrived / Check-In buttons adds a quick arrived/check-in button beside each player on the timesheet.
- Display message X hours before sunset shows a message on Admin, Member, and Visitor timesheets. It is display-only and does not change booking handling.
- Login timeout delay controls automatic logout after inactivity; a blank value uses the system default shown on the page.
- Confirm multiple bookings in a single email lets staff include other bookings by the same customer within a configured day range; blank disables it and 0 means same-day bookings only.
- Treat x-style player names as valid controls whether placeholder-style player entries count as valid players for utilisation/reporting purposes.
- Search Members when entering Player or Reservation Name shows matching members while typing in Timesheet and Booking Detail fields.
- Search Competitions when entering Reservation Name shows matching competitions on the date being displayed.
- Nightly backup email sends backup details for upcoming bookings.
- In-grid editor default create-new-booking controls whether adding players to an occupied tee time creates a separate booking or appends to the existing booking.
- Enable Squeeze Times shows the Squeeze Tee Time option and allows extra tee times before the first tee time, after the last tee time, or between existing tee times.
- Postal, email, and text marketing consent settings show consent controls on member booking, visitor booking, and edit-contact pages.

## Configure Timesheet

Configure Timesheet sets tee times and tee time intervals for days, date ranges, months, years, and course-specific schedules where applicable.

Use for:

- Creating a year's tee times.
- Changing intervals.
- Adding tee times to start/end of day.
- Squeezing additional tee times.
- Multi-course schedule setup.

Confirmed workflow:

1. Check Calendar End Year in System Configuration for new years.
2. Go to Tools > Configure Timesheet.
3. Use the Configure Timesheet form at the bottom of the page, below the calendar-style year overview.
4. In Operation, choose Configure one or multiple days with the same tee time interval or Configure one or multiple days with alternative tee time intervals.
5. If the club has more than one course or tee, use Course to choose the course being configured.
6. Select Year, Start Month, Start Day of Month, End Month, and End Day of Month.
7. Select the tee time interval or alternative intervals.
8. Select First Tee Time Hour, First Tee Time Minute, Last Tee Time Hour, and Last Tee Time Minute.
9. Select sunrise/sunset stopping rules where needed.
10. Tick the weekday checkboxes under Select the days of the week you want to configure.
11. Click Configure the Timesheet.

The live Configure Timesheet page also includes:

- Calendar-style year overview per course.
- Key for weekday, current day, weekend, and not-set-up days.
- Course selector.
- Delete selected tee times on one or multiple days.
- Timesheet Templates link for setting up reusable timesheets that can be copied quickly from one date to another.

## Green Fee Rates

Green Fee Rates configure categories and rates for manual staff-created bookings such as visitors, societies, member guests, and similar groups.

Distinguish:

- Manual booking green fee rates: Tools > Green Fee Rates.
- Online visitor/agent rates: Visitor Booking/online green fee setup.
- Member guest rate: Member Booking/member guest rate setup.

Never invent rate values. Rates are club-specific.

Write-capable demo crawl evidence for Tools > Green Fee Rates:

- The page can be year/month scoped, for example "Green Fee Rates for 2026".
- Controls and table columns include Select a Year, Add Green Fees, Filter Category, Category, Sub Category, Holes, Start Date, End Date, Rates, Mem Types, Default, Global, and Actions.
- Observed categories include Competition, Complimentary, Corporate, Guest, Hotel, Member, Member Guest, Other, Resident, Society, Tour Operator, Visitor, and Voucher.
- Hole-specific rows can exist, including separate 9-hole and 18-hole member/flex rows. When a course changes between 18 holes and 9 holes, check that the relevant rate route has a matching Holes value for the affected category/sub-category and date range.
- Green Fee Rates help launchers include creating online green fee rates, editing online green fee rates, holiday overrides, and copying green fee rates between years.

## Member casual booking rules

Member Casual Booking Rules control when members can view and book casual golf online.

Use when:

- Members cannot book a casual round.
- The club wants to change how many days in advance members can book.
- Guest booking needs enabling/disabling.
- Casual Golf Release Time is involved.
- Tee Time Locked behaviour is reported.

Check member status, membership type, and online booking settings alongside these rules.

The live rule page distinguishes View rules from Book rules. It explains that only tee times covered by configured rules are made available to members; all other times cannot be booked or viewed. Rule fields include course, start/end date, start/end time, rule type, days advance booking, guest booking allowed from, casual guests not allowed, number of players, players per tee time, guests, number of guests, days of week, and applies-to membership-type controls.

Write-capable demo crawl evidence for Member Casual Booking Rules:

- The rule table includes Key, Type, Start, End, Time, Advance, weekdays, Mem Types, and Actions.
- The edit/add form uses fields for course, Start Day/Month/Year, End Day/Month/Year, Start Hour/Minute, End Hour/Minute, booking type, days advance, Guest Booking Start Hour/Minute, weekday checkboxes, bookable player counts, player counts, and membership type selection.
- Membership type scope options include All Membership Types, Selected Membership Types ONLY, and All Membership Types EXCEPT those selected.
- Check both View and Book rules for the same course/date/time. A member may be unable to book because the Book rule is missing or scoped away even when a View rule exists.

## Visitor, agent, tour-operator, and day ticket rates

Visitor Booking setup includes:

- Online Green Fee Rates.
- Multi-Year Green Fee Rates.
- Golf Packages.
- Visitor/Agent rates.
- Day Ticket Rates.

Use these for online visitor/agent/tour-operator booking rates. Do not confuse them with manual Green Fee Rates for staff-created bookings.

Online visitor/agent/tour-operator green fee setup supports filtering by channel, enabled/all rates, years, months, and days. Rate rows distinguish golf-only rates and package rates, with columns for type, channel, package name, start/end date, multi-year flag, time, holes, weekdays, per-player prices, advance booking, and actions. Do not store actual rates from a club.

Day Ticket Rates are for visitors playing two rounds on the same day through the club website. The live page notes they are not supported for tour operators or third-party tee time agents. Fields include course 1, course 2, start/end date, green fee rate, type, days advance booking, and days of week.

Open Competitions for Visitors are configured from Tools > Open Competitions for Visitors. Fields include course, competition date, start/end time, competition name/reservation name, booking/playing format, competition type, member green fee, visitor green fee, mixed member/visitor teams, booking available date, and booking available time.

Visitor online booking evidence:

- The visitor-facing booking menu includes member online booking, visitor online booking, open days/competitions, and golf event booking routes.
- Visitor availability grids can show key values such as Tee Free, Booked, Member, Visitor, Guest/Member, Competition, Open Competition, Society, Corporate, Reserved, Reserved For Members, Reserved For Visitors, Closed, Special Offer, Course Maintenance, and Online.
- For GolfNow or Hot Deals display problems, check BRS visitor availability and BRS visitor/agent inventory first, then escalate if the external channel still shows the wrong hole count or availability after BRS settings look correct.

## Golf Events

Golf Events setup belongs in Tools/Golf Plus where enabled. Use for event-style golf booking rather than normal tee times or competitions.

The live Tools page describes Golf Events as setting up part of the timesheet for an event organiser to populate. This can be used for a member event, corporate day, or similar event.

Golf Event admin fields include course, event date, event start/end time, event name/reservation name, and event username. Only tee times matching the event date, start time, end time, and reservation name are made available to the external event organiser.

## APPROVED ANSWER: green-fee-rates
When configuring green fee rates, confirm:
1. The date range.
2. Whether the rate is for manual staff-created bookings, online visitors/agents, member guests, tour operators, or day tickets.
3. Weekday/weekend setup.
4. Whether the rate applies to all times or specific tee times.
5. Whether restrictions apply.

When configuring booking rules, check:
- Who can book.
- How far in advance bookings can be made.
- Time restrictions.

## APPROVED ANSWER: tee-sheet-setup
For tee sheet or timesheet setup, use Tools > Configure Timesheet when configuring the actual tee time grid.

Before changing the setup, confirm:
- Year.
- Start and end date range.
- First and last tee time.
- Tee time interval, or both alternate interval values if using alternate intervals.
- Days of the week affected.
- Course, where the club has more than one course.
- Sunrise/sunset limits if they are part of the requested setup.
## END APPROVED ANSWER

## APPROVED ANSWER: buggy-booking-availability
Buggy booking setup is controlled from System Configuration where the club's buggy settings are enabled.

Check:
1. Number of buggies available.
2. How long each buggy is needed before and after a round.
3. Whether visitors are allowed to book buggies online.
4. Whether the club expects the buggy price to be added by staff after booking.

After changing buggy settings, click Update on System Configuration and then check the timesheet to confirm buggy availability is appearing as expected.
## END APPROVED ANSWER
