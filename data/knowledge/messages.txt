BRS KNOWLEDGE FILE: MESSAGES

Use this file for BRS admin Messages, system announcements, club messaging, email messaging, text/SMS messaging, timesheet messages, service reminder emails, and communication templates.

Source basis:
- Public BRS Help Center: Communication via Email and Text section and Club Messaging article.
- Approved system crawl: Messages page, Email Messages menu, dashboard messaging shortcuts, and Tools index.
- Built-in product text observed in the system crawl.

Support style:
- Distinguish BRS system Messages from club-to-member communication tools.
- For message delivery problems, ask whether the issue is email, SMS, club app push notification, or timesheet message.
- Do not quote sent message contents, recipients, or delivery history from a club account.

Observed message categories and filters include:

- Favourites.
- Announcements.
- System Messages.
- Title search.
- Start Date.
- End Date.
- Reset filters.
- Pagination.

The page can contain information about:

- New features.
- General news applicable to the club.
- Scheduled maintenance.
- Downtime.

Actual message contents, dates, read state, favourites, and club-specific notices are operational data.

## Club Messages / app push messages

Club Messages are found in the Tools area and can also appear from dashboard messaging shortcuts. They support member communication through the BRS Members Booking App or New Members Website.

Club Messages can be used to:

- Send push notifications to all members.
- Send to selected members.
- Send by membership group.
- Send by membership type.
- Send to members on the tee sheet on a specific day.
- Send messages to members while they are on the course.
- Send to all members.

Examples of appropriate content include course closure notices, social event updates, competition results, and clubhouse messages. The chatbot should describe the feature, not draft or store club-specific message content unless the user asks for a draft in the current conversation.

The live Club Messaging page names these options:

- Message Membership Types.
- Message Membership Groups.
- Message Selected Members.
- Message The Timesheet.
- Message The Course.
- Message All Members.

It also shows recently sent club messages and a report link for previous club messages. Useful columns include message subject, message type, sent date/time, and count. Do not store live message subjects.

## Email messaging

Email messaging lets staff send targeted emails to member and contact audiences.

Observed email options include:

- Email Membership Types.
- Email Membership Groups.
- Email Selected Members.
- Email the Timesheet.
- Email Contacts.
- Member App Reminder.
- BRS Registration Reminder.
- Golf Plus Reminder.

Use these distinctions:

- Email Membership Types targets members by membership type.
- Email Membership Groups targets members assigned to groups.
- Email Selected Members lets staff choose a specific list of members.
- Email the Timesheet targets people linked to bookings on a date/time.
- Email Contacts targets non-member contacts such as visitors, societies, hotels, companies, or tour operators.
- Golf Plus Reminder sends a predefined email about Golf Plus.

The live Email Messaging page shows recently sent messages and a report link for previous messages. Useful columns include username, date/time sent, email message, number of emails, attachments, and marketing flag. Do not copy message content, usernames, or attachment names from a live club.

## Recipient delivery troubleshooting

Use this when a member, contact, customer, visitor, or staff user is not receiving BRS emails, SMS/texts, club messages, password reset emails, booking confirmations, or registration/reminder messages.

Do not answer delivery-failure questions with the normal "Email Membership Types", "Email Membership Groups", or "Email Selected Members" sending workflow unless the user asks how to send a new email.

Recommended checks:

- Identify the channel and message type first: email, SMS/text, club message, password reset, booking confirmation, registration reminder, or another BRS message.
- Open the record that owns the recipient details. For a member email-delivery issue, open the member profile/details page from Users because the Unsuppress button is visible on the Users side. For a contact, use Contacts. For staff/admin users, use Users.
- Confirm the email address or mobile number is correct, current, and saved on that record. Check for duplicate records or an old address on a booking, contact, member, or user profile.
- For email, check whether an Unsuppress button is shown beside the email address. If Unsuppress is shown, the address is suppressed by the BRS/email delivery system; only unsuppress it after confirming the recipient wants to receive messages. If no Unsuppress button is shown, there is no visible suppression on that profile.
- Check whether the message type depends on consent, marketing preference, opt-in, app registration, member status, membership type, membership group, contact category, or user permissions.
- Check the original sent-message area or report for that channel, such as Email Messaging, SMS/text messaging, club messaging, recent messages, or the related report, and confirm the recipient was included in the selected audience.
- Ask the recipient to check spam/junk, mailbox full or blocked sender rules, and any business email allowlist settings if they use a managed mailbox.
- If the address or mobile is correct, the recipient was in the audience, there is no visible suppression or opt-out issue, and messages still do not arrive, escalate to BRS Support with the recipient record, address/mobile, message type, sent date/time, and what has already been checked.

Common causes:

- The recipient was not in the selected audience because of membership type, group, contact category, timesheet selection, status, or app-registration requirements.
- The email address was suppressed after a bounce, complaint, or repeated delivery failure.
- The address or mobile number exists in more than one place and the message used a different record than expected.
- The message is a marketing communication and the recipient is not opted in, even though transactional emails may still work.

## Text/SMS messaging

The Help Center communication section includes SMS guidance for:

- Sending a text message to the timesheet.
- Viewing sent text messages.
- Sending text to membership categories.
- Sending text to contacts/visitors.
- Sending text to membership groups.
- Sending text to selected members.
- Topping up SMS credit.
- SMS cost.
- Enabling SMS.
- Sender ID questions.

When troubleshooting SMS:

- Confirm the audience type.
- Check SMS credit if messages are not sending.
- Check whether SMS is enabled.
- Check sender ID behaviour only from approved guidance or escalate.

The live Text Messages page shows current SMS balance, setup options, Purchase Text Messaging Credit, recently sent messages, and a report link for previous messages. Useful columns include username, date/time sent, message, number of mobiles, and marketing flag. Do not copy sent message text, phone opt-out text, usernames, or current balance values into reusable knowledge.

## Timesheet messages

Timesheet messages are configured/managed from communication tools and can display messages on the timesheet for staff or customers, depending on setup.

Use for:

- Daily operational notes.
- Playing schedule notes.
- Titles for each day.
- Adding or deleting a message on the timesheet.

If the user asks about a message attached to a booking, clarify whether it is a booking note, customer communication, or a timesheet-wide message.

## Email and letter templates

Tools includes Email and Letter Templates. These are used to set reusable communication templates rather than one-off messages.

Use templates when the user asks about standard wording used repeatedly. Use email/text messaging areas when the user asks about sending a current message to a specific audience.

## Service reminders

Service reminder emails are part of communication workflows for reminders such as member app reminders or BRS registration reminders. Use these when the club wants to prompt members to register, use the app, or complete an expected action.

## Permissions and missing options

Messaging options can depend on:

- Enabled modules such as Members Booking App, SMS, or member booking.
- User group permissions.
- Club configuration.
- Available contact/member data.

If the user cannot see a messaging option, ask which user group they are logged in as and whether the relevant module is enabled.
