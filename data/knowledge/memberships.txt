BRS KNOWLEDGE FILE: MEMBERSHIPS

Use this file for Memberships, member profiles, membership types, member billing, bills, subscriptions, payment schemes, scheduled payments, flexible membership, wallets/account balances, member online booking access, member app topics, and member-facing booking rules.

Source basis:
- Public BRS Help Center: Flexible Membership, Member Booking, User Management membership articles, and Memberships create-bills overview.
- Approved system crawl: user/member concepts, online member booking surfaces, messaging options, and reports relationships.
- Existing approved support logic for membership object routing.

Support style:
- Keep membership billing separate from booking payments unless a booking payment is explicitly involved.
- For member bill/payment/refund questions, use the member profile or Memberships billing route first, not generic BRS Payments.
- Do not repeat member names, balances, bill amounts, wallet balances, or subscription details from live data.

Priority answer cues:
- For one new member who needs a prorated bill, prefer Memberships > Members > open/create that member > member billing/bills area. Tell the user what to enter: billing reference/description, due date, bill period/start/end dates, subscription or ADD ITEM, quantity 1, prorated amount, payment scheme only if instalments are wanted, then Preview/confirm/publish checks.
- Use Memberships > Billing/Payments > CREATE BILLS for batch bills or when the club deliberately wants the bill wizard. In the wizard, use Billing Reference, Due Date, Set Bill Filters, cycle/period dates, Who To Bill, subscriptions/custom bill items, Payment Schemes, Preview, Review/Confirm, and Publish Bill.
- If a person appears in Users/BRS users but not Memberships or Flex/Flexible Members, do not tell the user to open a missing member profile. First check the user account's linked member profile, Membership Type, Flex flag on the membership type, dashboard FLEX MEMBERS view, and import/category mapping before creating a duplicate.
- Flexible membership setup spans Membership Types, Members, Accounts/wallets, and Settings. Use Accounts for wallet/account setup, not booking payments.

## Main purpose

Memberships is the area for managing member records and membership-related financial/access workflows. It covers member profiles, membership types, subscriptions, bills, billing/payment views, wallets or account balances, and membership reports.

In the live demo system, Memberships opens an embedded memberships app. Its main navigation is:

- Dashboard.
- Members.
- Membership Types.
- Subscriptions.
- Billing/Payments.
- Reports.
- Accounts.
- Settings, shown as the cog icon.

Use Memberships when the user mentions:

- Member profile.
- Membership type.
- Subscription.
- Bill or invoice.
- Billing cycle.
- Payment scheme/payment plan.
- Scheduled membership payment.
- Wallet/account balance.
- Flexible/flexi membership.
- Member access to online booking.

## Member profile

For one individual member, use Memberships > Members to find or create the member record. The live Members page exposes a member list/search surface and a Create Member action.

Use the visible member record/actions for the task the user describes. Do not name a specific member-profile tab unless the user can see it or another approved source confirms it.

If a staff member or employee needs admin access, use Users, not Memberships.

The Members page supports member lookup/listing and includes a Create Member action. Observed member table columns include title, first name, last name, email, membership card number, membership type, membership status, and actions. These columns are useful for explaining what staff can filter/check, but actual member details are customer data and must not be copied into answers.

## Membership types

Membership types classify members and can affect:

- Online booking access.
- Booking rules.
- Member guest rates.
- Timesheet colour display where configured.
- Billing/subscriptions.
- Membership reports.

Membership type setup is covered in User Management/Tools-related Help Center articles. Typical tasks include add, edit, delete, mapping/import, and adding colours to membership types on the timesheet.

The Membership Types page includes actions such as Create Membership Type and Membership Type Changes. Observed columns include name, flex flag, status, minimum age, maximum age, qualifying length of service, next chained membership type, default subscriptions, and actions.

Use Membership Types when the user is changing membership categories or the rules/default subscriptions attached to a category. Use Members when changing one person. Use Subscriptions when changing the financial product/fee being assigned.

## Create or edit a flexible membership type

Use Memberships > Membership Types when the user asks how to create, add, set up, edit, or configure a flexi/flexible membership type. Do not send this question first to a member profile; a member profile is where a club assigns or reviews an existing type for one member.

Observed route:

1. Open Memberships.
2. Open Membership Types.
3. Click CREATE MEMBERSHIP TYPE.
4. In Membership Type Details, enter Name.
5. Choose Select Membership Type Status. Observed status options are Active and Inactive.
6. Tick Flex to make the membership type a flexible membership type.
7. Use Minimum Age and Maximum Age only when the membership type is age-limited.
8. Use Qualifying Length of Service only when eligibility depends on years of service.
9. Use Next Chained Membership Type only when members should later move to another membership type.
10. In Subscription Items, use the search box and Select buttons to add default subscriptions to the membership type.
11. Review the Default Items table.
12. Click CREATE.
13. Return to Membership Types and check the row shows Flex as Yes.

Observed create/edit fields and controls:

- Name.
- Select Membership Type Status.
- Flex checkbox.
- Minimum Age.
- Maximum Age.
- Qualifying Length of Service.
- Next Chained Membership Type.
- Start typing to filter available subscriptions.
- Select, used to add a subscription item.
- Default Items table.
- CANCEL.
- CREATE.

Use Membership Types > open an existing flexible type when the club wants to inspect or edit an existing flex type. The detail view shows the Flex checkbox as checked, the default subscription items for that type, the members assigned to that type, DELETE where allowed, and EDIT.

Related but separate flexible membership setup:

- Memberships > Settings > General includes Display Flexible Wallets table on dashboard. This controls whether the flexible wallets table appears on the Memberships Dashboard; it does not create the membership type.
- Memberships > Accounts is for configured wallets/accounts.
- Members > open member profile is for assigning/reviewing the type and member-specific account balances.

## Subscriptions

Subscriptions define membership charges/products that can be assigned to members or membership types.

The Subscriptions page includes actions such as:

- Apply/Remove Subscription.
- Create New Subscription.
- Viewing cycles attached to subscriptions.

Observed subscription table columns include name, cost, tax rate, status, count members, cycles, count subscriptions, and actions.

Use Subscriptions when the user asks about recurring membership fees, subscription setup, subscription cycles, or applying/removing a subscription from members. Use Billing/Payments when the bill has already been created or payment status is the issue.

## Create bills

Approved Help Center overview for creating membership bills:

1. Click Memberships.
2. Click Billings/Payments.
3. Click Create Bills.
4. Step 1: enter billing details.
5. Step 2: click Set Bill Filters.
6. Fill out bill cycle information.
7. For All Cycles, enter dates.
8. For Selected Cycles, select the cycle, enter information, then click Add Cycle/Period.
9. Click Next.
10. Fill out Who to Bill.
11. For selected members, check the members to bill.
12. For selected membership types, check the membership types to bill.
13. For custom filters, click Select Filter and choose the filter.
14. Click Save.
15. Step 3: select the desired subscriptions.
16. Drag selected subscriptions into priority order for payment allocation.
17. Add custom bill items if needed.
18. Select payment schemes.
19. Click Preview.
20. Review and Confirm.
21. Fill out Publish Bill information.
22. Click Publish Bill.

Payment allocation priority matters when members pay through payment schemes or alternative arrangements. It determines how the payment is allocated across subscriptions in the bill. The Payments by Subscription Type report shows allocation.

The live Billing/Payments page includes View Payments and Create Bills. Observed bill list columns include reference, bill raised, bill due, payment status, publish status, count, expected revenue, received revenue, and actions.

Use Billing/Payments for:

- Reviewing batches of bills.
- Checking bill due dates and payment status.
- Creating bills.
- Viewing payments linked to membership billing.
- Publishing or reviewing bill batches where available.

## Unpaid or outstanding member bills

Use Memberships reports/billing views for unpaid or outstanding member bills.

Suggested support answer:

1. Open Memberships.
2. Go to Billing/Payments or Memberships > Reports depending on the club's interface.
3. Look for unpaid, outstanding, failed, or balance due filters.
4. Narrow by billing cycle, period, date range, or membership type.
5. Export/download the list if the view provides an export option.

For one member, open the member profile and check Billing rather than using the all-member report.

The Memberships Dashboard can surface panels for bills, overdue bills, failed scheduled payments, and flexible members. Those panels are useful shortcuts, but the actual names, dates, balances, and failures shown are live member/payment data.

## Payment schemes and scheduled payments

Payment schemes are used for scheduled membership payments or payment plans.

To create or manage the payment scheme itself, use Memberships > Settings > Payment Schemes.

When the user asks how to create, add, set up, edit, or manage a payment scheme, answer with the Memberships > Settings > Payment Schemes route. Do not send them to a member profile or bill unless the question asks how to apply, attach, link, select, or use an existing payment scheme on a specific membership bill.

When troubleshooting missed scheduled payments:

- Check whether the member was Active before the scheduled payment date.
- Check the payment scheme attached to the bill.
- Check failed payment status and retry behaviour from approved local guidance.
- Check the bill/payment record before escalating to payments platform support.

If the issue is a card transaction, payout, refund record, or BRS Payments processor issue, use Payments/Tools > BRS Payments evidence as well.

## Membership bill refunds or reversals

For a refund on a membership bill, use Memberships billing/payment evidence rather than the tee sheet booking refund route.

Confirm the correct member, bill, payment, amount, and allocation before refunding or reversing. If the payment was taken through BRS Payments, review refund records under Tools > BRS Payments > Refunds.

## Flexible membership

Flexible Membership is an optional feature. The Help Center says clubs should contact their account manager or sales/support to add it.

Flexible/flexi membership setup spans Membership Types, Settings, Accounts, and the member profile:

- Use Membership Types to create or edit the flexible membership type and tick Flex.
- Use Settings > General to show or hide the flexible wallets table on the Memberships Dashboard.
- Use Accounts for wallet/account setup.
- Use Members to assign or review an existing flexible type on one member and manage that member's account balance.

Flexible/flexi membership is not handled from booking payments.

If a person appears in Users but is not appearing in Memberships or the flexible-membership view, check the linked relationship before telling the staff member to open a missing Memberships profile. Users and Memberships records are linked, but a visible user account does not by itself prove the Memberships member profile/filter is present. Check the Users record, linked member profile, Membership Type, Flex flag on the Membership Type, Memberships dashboard FLEX MEMBERS view, and Club Systems member/category mapping or preview/sync evidence before creating a duplicate profile.

## Wallet/account balances

Flexible Membership wallets can be edited using top-ups and clawbacks.

Approved Help Center workflow:

1. Click Memberships.
2. Use the Memberships Dashboard to locate the flexible member.
3. Search for and select the member.
4. Click Edit Balance.
5. Choose Transaction Type: Topup or Clawback.
6. Decide whether to Record Payment.
7. Select Payment Type if recording payment.
8. Enter the top-up amount in points.
9. Add transaction notes.

Topup adds points to the wallet. Clawback withdraws points from the wallet. The wallet workflow exposes a transaction-note field for member-visible notes where the system displays wallet transactions.

If transferring balances from another system, Help Center guidance says Record Payment should be unticked.

The Accounts page lists configured membership wallets/accounts. Observed account columns include account name, units, auto assign, active, and minimum balance. Use Accounts for wallet/account setup questions. Use a member profile or dashboard flexible-member panel for one member's balance/action.

## Member online booking

Member Booking is the member-facing login surface. It supports:

- Member username/password login.
- Registration.
- Forgot username.
- Forgot password.
- Member booking through the BRS Members App or member website where enabled.

If a member cannot book a casual round, check:

- Member status and profile.
- Membership type.
- Member online booking enabled.
- Member Casual Booking Rules.
- Casual Golf Release Time.
- Tee Time Locked behaviour.
- Guest booking restrictions.

## Member app and club messages

Members Booking App topics include registration, app use, member account updates, and receiving Club Messages. Club Messages can target all members, selected members, members by membership type/group, or members on the tee sheet.

Use Messages for sending communications. Use Memberships/Users for fixing member access and profile setup.

## Decision-tree direct answers

These blocks support legacy decision-tree direct routes. Keep them factual and short.

## APPROVED ANSWER: create-member-profile-account
Member booking accounts are handled through member registration and the member profile, not through a visitor account route.

Use this route when the user means a member profile/account:

1. Give the member the club's BRS Members Tee Time Reservation URL, or add that URL to the club website.
2. The member registers their details through the club website/member booking link.
3. The club verifies the registration.
4. Enable the member's profile once the registration has been verified.
## END APPROVED ANSWER

## APPROVED ANSWER: create-membership-bill
Membership bills are created from Memberships > Billing/Payments.

Use this route for subscription, renewal, batch, or all-member billing work:

1. Open Memberships.
2. Open Billing/Payments.
3. Click CREATE BILLS.
4. Enter the Billing Reference and Due Date.
5. Click SET BILL FILTERS and choose the bill cycle or period option: All Cycles, Selected Cycles, or No Cycles/Periods.
6. Use the Who To Bill step to confirm which members or audience should receive the bill.
7. Select the subscriptions, discounts, and any custom bill items needed. Use ADD ITEM only when the club needs an extra one-off line item.
8. In Payment Schemes, select a scheme only if members should be offered scheduled or instalment payments. Leave payment schemes unselected when the bill should be paid annually in one lump sum.
9. Click PREVIEW and review the member/audience, bill reference, due date, subscriptions, custom line items, discounts, payment options, and totals before finalising.

Check the result from Billing/Payments by using View All Bills or the bill search/filter controls, then confirm the bill appears with the correct member or audience, due date, amount, payment status, and publish status.

For a manual one-off charge on a single member, open the relevant member profile and use that member's Billing area instead.
## END APPROVED ANSWER

## APPROVED ANSWER: payment-scheme-setup
Payment schemes are used for scheduled membership payments.

Before setting one up or changing one, confirm:

1. Correct member.
2. Linked bill.
3. Scheme start date.
4. Payment frequency.
5. Amount.
6. Member status.
7. Failed payment reason, if the issue is about a failed scheduled payment.
## END APPROVED ANSWER

## APPROVED ANSWER: membership-unpaid-bills-report
Use Memberships reports and billing views for unpaid or outstanding membership bills.

Start with Memberships > Reports and check the financial reports, especially Overdue Bills and Bills Overview where available. For one member, open the member profile and check their Billing area instead.

Filter/check:
- Bill status or overdue/unpaid status where available.
- Billing cycle or date range where relevant.
- Member name, bill status, balance due, due date, and payment status.

Use export/download controls from the report view where the page provides them.
## END APPROVED ANSWER
