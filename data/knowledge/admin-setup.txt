# ADMIN SETUP – SUPPORT KNOWLEDGE

Use this knowledge for system setup, configuration, green fee setup, email templates, admin configuration, and general BRS setup questions.

---

## CORE RULE

Always confirm what the user is trying to configure before giving detailed steps.

Common setup areas:

- Green fee rates
- Booking rules
- Email templates
- User/admin settings
- Tee sheet configuration
- Membership/billing settings

---

## GREEN FEE RATES

Use when the user asks about setting up or changing green fees.

Typical checks:

1. Confirm the date range
2. Confirm visitor/member rate
3. Confirm weekday/weekend rules
4. Confirm whether the rate applies to all times or specific times
5. Confirm whether any restrictions apply

If unsure whether the rate is correct, advise checking the configured rate against a live tee time.

Escalate if:

- The rate does not apply after setup
- The system price differs from the configured rate
- Multiple clubs/rates are affected

## BUGGY BOOKING / BUGGY MANAGEMENT

Use when the user asks how to modify the buggy count, switch on buggy booking, or allow visitors to book buggies online.

Advise the user to go to Tools > System Configuration, then find the Buggy Booking section.

In this section they can configure:

- Number of Buggies the club has
- The amount of time each buggy is needed before a round
- The amount of time each buggy is needed after a round, for example for charging or cleaning
- Whether visitors are allowed to book buggies online

If "allow visitors to book buggies online" is enabled and the Number of Buggies is greater than zero, visitors will see buggy availability against each tee time and can book 1 or 2 buggies when available.

Make clear that the buggy price is not included at the time of booking. Staff must add the buggy charge afterwards at the club.

If any changes are made, the user must click Update at the top or bottom of the page to save them.

After setup, advise the user to return to the timesheet. The available buggy count will appear on the right-hand side and will change depending on buggy allocations before and after tee times.

Example explanation: if the club has 10 available buggies and the 09:00 tee time has 1 buggy allocated, only 9 buggies may be available for the relevant time before and after that tee time.

Escalate if:

- Buggy settings do not save after clicking Update
- Buggy counts do not appear on the timesheet after setup
- Online buggy availability does not match the configured number of buggies
- Visitors cannot book buggies even though the setting is enabled

## ADMIN CONFIGURATION

Use when the user asks about general admin settings.

---

## SAFE BEHAVIOUR

Always confirm before advising changes that affect live customer/member experience.

Confirm before:

- Changing live booking rules
- Updating rates
- Editing email templates
- Changing member access
- Removing availability

---

## ESCALATION TRIGGERS

Escalate if:

- A setting does not save
- A live system result does not match configuration
- Multiple users/clubs are affected
- The user is unsure which setting controls the behaviour
- The requested setup could affect payments, billing, or customer access

---

## RESPONSE STYLE

Keep setup answers practical.

Preferred format:

1. Confirm what they are configuring
2. Give exact area to check
3. Provide 1–3 next steps
4. Ask one follow-up if needed
