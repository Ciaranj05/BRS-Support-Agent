# ADMIN SETUP – SUPPORT KNOWLEDGE

Use this knowledge for system setup, configuration, green fee setup, email templates, admin configuration, and general BRS setup questions.

---

## CORE RULE

Only confirm what the user is trying to configure when the setup area is unclear.

If the user clearly states the setup area and an approved answer exists, return the approved answer directly without asking a follow-up question.

Never invent navigation paths, setup locations, or configuration steps that are not present in the approved knowledge.

Common setup areas:

- Green fee rates
- Booking rules
- Email templates
- User/admin settings
- Tee sheet configuration
- Membership/billing settings

---

## GREEN FEE RATES

Use when the user asks about setting up or changing green fees.

## APPROVED ANSWER: green-fee-rates
nWhen configuring green fee rates, confirm:
1. The date range
2. Visitor or member pricing
3. Weekday/weekend setup
4. Whether the rate applies to all times or specific tee times
5. Whether restrictions apply

After setup, always verify the configured rate against a live tee time to confirm the correct price is displaying.
## END APPROVED ANSWER

Escalate if:

- The rate does not apply after setup
- The system price differs from the configured rate
- Multiple clubs/rates are affected

---

## BOOKING RULES

Use when configuring booking restrictions.

## APPROVED ANSWER: booking-rules
When configuring booking rules, check:
- Who can book
- How far in advance bookings can be made
- Time restrictions
- Player limits
- Member or visitor access
- Online availability

Always confirm the exact rule before changing live booking behaviour.
## END APPROVED ANSWER

## EMAIL TEMPLATES

Use when the user asks about confirmation emails, reminders, or customer emails.

## APPROVED ANSWER: email-templates
When updating email templates, confirm:
1. Which template is being updated
2. Whether it applies to bookings, payments, memberships, or general communication
3. Whether merge fields are being used
4. Whether a test email has been sent

## TEE SHEET SETUP

Use when the user asks about tee sheet configuration.

## APPROVED ANSWER: tee-sheet-setup
When configuring the tee sheet, check:
- Opening and closing times
- Tee intervals
- Number of holes
- Booking slots
- Visitor and member availability
- Blocked times
- Competition or society bookings

After updating the setup, verify the live tee sheet matches the configured availability and restrictions.
## END APPROVED ANSWER

Escalate if:

- Tee times do not display correctly
- Rules apply inconsistently
- Live availability does not match setup

## BUGGY BOOKING / BUGGY MANAGEMENT

Use when the user asks any question about buggy booking, buggy setup, buggy availability, buggy counts, buggy numbers, or buggies online.

If a buggy question is not covered by the approved answer below, be transparent that the current approved buggy guidance only covers buggy booking setup and availability.

## APPROVED ANSWER: buggy-booking-availability
Here you enter the Number of Buggies the club has, and the amount of time each buggy is needed before and after each round (for charging, cleaning etc).
The allow visitors to book buggies online setting, if checked, and the number of buggies setup is greater that zero, visitors will see the number of buggies available against each tee time and will be able to book either 1 or 2 buggies as long as they are available to be booked.
Note that the price of the buggy is not included at the time of the booking so must be added in afterwards by staff at the club.
If any changes are made click "Update" at the top or bottom of the page to save your changes.
Once you have set up this, go back to the timesheet and you will see the number of buggies appearing on the right hand side of the screen. This number will fluctuate depending on how many buggies are available See the image below. The are 10 available buggies, but because the 09:00 tee time has 1 buggy against it, only 9 are available for a time before and after the tee time.
## END APPROVED ANSWER

Escalate if:

- Buggy settings do not save after clicking Update
- Buggy counts do not appear on the timesheet after setup
- Online buggy availability does not match the configured number of buggies
- Visitors cannot book buggies even though the setting is enabled

## ADMIN CONFIGURATION

Use when the user asks about general admin settings.

Before giving steps, identify the setting area:

- Users
- Booking rules
- Payments
- Memberships
- Tee sheet
- Email templates
- Reports

If the request involves permissions, use user-management knowledge.

---

## SAFE BEHAVIOUR

Always confirm before advising changes that affect live customer/member experience.

Confirm before:

- Changing live booking rules
- Updating rates
- Editing email templates
- Changing member access
- Removing availability

---

## ESCALATION TRIGGERS

Escalate if:

- A setting does not save
- A live system result does not match configuration
- Multiple users/clubs are affected
- The user is unsure which setting controls the behaviour
- The requested setup could affect payments, billing, or customer access

---

## RESPONSE STYLE

Keep setup answers practical.

Preferred format:

1. Confirm what they are configuring only if unclear
2. Give exact area to check
3. Provide concise next steps
4. Ask one follow-up only when needed
